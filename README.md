# Fortune Cookies for Machines

One fortune-cookie message an AI agent would crack open: a single line
of at most 200 characters, written to `/output/entry.txt` by `main.py`.

> You will meet your maker. He is on PTO.

## Entry

`main.py` writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when unset) as one line with no trailing
newline, after validating the kit gate exactly: 1–200 characters,
not only whitespace.
